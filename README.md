# Joice Portfolio

Portfolio personal satu halaman untuk mahasiswa Information Systems yang menampilkan profil, proyek, keterampilan, pengalaman akademik, dan formulir kontak yang responsif.

## Deskripsi

Proyek ini dibuat sebagai tugas mandiri Praktikum Minggu 02 dengan fokus pada penggunaan HTML5 dan CSS3. Website ini menampilkan profil profesional Joice Anastasya Napitupulu, pengalaman akademik, project highlight, skills, serta formulir kontak untuk kolaborasi proyek.

Tujuan utamanya adalah menampilkan portofolio yang modern, bersih, dan mudah dibaca dengan pendekatan desain yang user-centered.

## Fitur Utama

- Layout satu halaman yang modern dan profesional
- Struktur HTML5 semantic: `header`, `nav`, `main`, `section`, `article`, dan `footer`
- Tabel riwayat akademik dan proyek dengan `caption`, `thead`, `tbody`, `tfoot`, serta atribut `scope`
- Daftar proses kerja menggunakan `ol` dan `li`
- Form kontak dengan `fieldset`, `legend`, `label`, validasi native, dan `aria-describedby`
- Layout responsif menggunakan CSS Grid dan Flexbox
- Desain visual yang konsisten dengan kombinasi warna dusty pink, soft gray, dan teks berani
- Penggunaan font modern dari Google Fonts (`Cormorant Garamond` dan `Manrope`)

## Teknologi yang Digunakan

- HTML5
- CSS3
- Google Fonts
- Responsive Design dengan media queries
- Vanilla CSS (tanpa framework)

## Prasyarat Instalasi

Sebelum menjalankan proyek, pastikan perangkat Anda sudah memiliki:

- Browser modern (Chrome, Edge, Firefox)
- VS Code (opsional, untuk editing dan Live Server)
- Ekstensi Live Server di VS Code (opsional)

## Cara Menjalankan

1. Clone repository ini:

```bash
git clone https://github.com/JoiceNapitupulu/ppw-2026-week2-12S24020.git
```

2. Masuk ke folder project:

```bash
cd ppw-2026-week2-12S24020
```

3. Buka file `index.html` di browser, atau jalankan dengan Live Server di VS Code.

Contoh alternatif:

```bash
start index.html
```

## Susunan Project

```text
.
```

Penjelasan:

- `index.html` — struktur utama halaman portfolio

## Contoh Penggunaan

Anda dapat membuka halaman ini untuk melihat profil portfolio, seperti:

- profil singkat dan tagline
- daftar proyek yang telah dikerjakan
- skillset dan kemampuan teknis
- pengalaman akademik dan proyek utama
- formulir kontak untuk kolaborasi

Jika Anda ingin menyesuaikan konten, edit file `index.html` dan `style.css` sesuai kebutuhan.
